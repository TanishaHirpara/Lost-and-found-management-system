CAMPUS LOST AND FOUND - STUDENT LEVEL VERSION

Files:
1. index.html - HTML structure
2. style.css - simple CSS styling
3. script.js - simple JavaScript functionality

Features:
- Register and Login
- Report Lost Item
- Report Found Item
- Search Items
- Submit Ownership Claim
- View Claim Status
- Administrator Login
- Approve or Reject Claims
- View Reports
- Reset Demo Data
